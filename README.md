## 📌 Опис проєкту
**ITCompass** — це комплексний освітній веб-портал та сервіс наставництва, покликаний вирішити проблему розгубленості початківців при виборі спеціальності в IT. 

Проєкт включає:
1. **Каталог 16 актуальних IT-професій** за 6 категоріями (Software Engineering, Тестування ПЗ/QA, Data/AI/ML, Інфраструктура та безпека, Design, Management & Analytics).
2. **Детальні модальні вікна та сторінки спеціальностей** із розбивкою обов'язків за грейдами (Junior / Middle / Senior), матрицею Hard & Soft навичок та посиланнями на офіційну документацію.
3. **Каталог верифікованих IT-менторів** з реальними кейсами, стеком технологій та погодинними ставками.
4. **Форму запису на 1-on-1 консультації**, пробні технічні співбесіди (mock-interview) та аудит резюме.
5. **Серверну частину на Python (Flask)** із повноцінним REST API, SQLite базою даних та панеллю адміністратора за адресою `/admin`.

## 🛠 Використані технології та стандарти
* **Frontend:**
  * **HTML5:** 100% семантична розмітка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<form>`).
  * **CSS3:** Сучасна верстка на базі Flexbox та CSS Grid, використання CSS Custom Properties (змінних) відповідно до затвердженого брендбуку.
  * **JavaScript (ES6+):** Асинхронне спілкування з бекендом (`fetch`), інтерактивне перемикання фільтрів, динамічні модальні вікна, клієнтська валідація форм.
  * **SVG:** Оптимізована векторна графіка без втрати якості та зайвої ваги.
  * **W3C Standards & WCAG 2.1 AA:** Повна валідність коду, семантика тегів, наявність атрибутів `alt` у зображень та `href` у посилань, висока контрастність для доступності.
* **Backend:**
  * **Python 3.9+:** Серверний рушій.
  * **Flask:** Легкий та продуктивний веб-фреймворк для обробки маршрутів, роздачі статики та REST API.
  * **Flask-Cors:** Забезпечення безперешкодної взаємодії з фронтендом за будь-якого середовища запуску.
  * **SQLite 3 (`itcompass.db`):** Автономна реляційна база даних (таблиці `professions`, `mentors`, `bookings`, `reviews`) з підтримкою транзакцій ACID.
  * **Admin Dashboard (`/admin`):** Вбудована панель керування заявками з можливістю підтвердження/скасування та автогенерацією кімнат Google Meet.

## 🚀 Як запустити проєкт локально

### Варіант 1. Запуск разом із Python Flask бекендом (Рекомендовано):
1. Запустіть файл **`start_backend.bat`** (подвійний клік у Провіднику).
2. Скрипт автоматично перевірить Python, встановить залежності (`Flask`, `Flask-Cors`) та відкриє у вашому браузері:
   * Головний сайт: [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
   * Панель адміністратора: [http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin)

### Варіант 2. Запуск тільки статичного фронтенду:
1. Відкрити файл `index.html` безпосередньо у будь-якому веб-браузері (подвійний клік на файл `D:\Web\index.html`).
2. Або відкрити папку `D:\Web` у VS Code та натиснути **Go Live** (Live Server).
