# ITCompass

**ITCompass** — інтерактивний довідник IT-професій та платформа підбору менторів для початківців.

Навчальний проєкт з дисципліни «Веб-розробка та проєктування веб-застосунків»
(НТУУ «КПІ ім. Ігоря Сікорського», ННК ІПСА, студент гр. КА-43 Трофімов Григорій).

## Сторінки сайту

| Файл | Призначення |
|------|-------------|
| `index.html` | Головна сторінка з hero-блоком, перевагами сервісу та добіркою популярних спеціальностей |
| `professions.html` | Каталог 16 IT-професій з фільтрами за напрямками та модальними вікнами деталей |
| `profession-frontend.html` | Детальний профіль спеціальності Frontend Developer |
| `mentors.html` | База менторів з профілями, стеком технологій і ставками |
| `contacts.html` | Контакти та форма запису на консультацію з клієнтською валідацією |
| `success.html` | Сторінка підтвердження надсилання заявки |

## Лабораторна робота №2 — Створення структури веб-проєкту

Мета: створити базову структуру вебсайту відповідно до попереднього планування, організувати файли та каталоги проєкту, застосувати семантичні елементи HTML, забезпечити доступність та валідність коду.

Що зроблено:

- **Структура проєкту** — стандартна ієрархія каталогів (`css/`, `images/`, сторінки в корені, `.gitignore`); усі файли мають зрозумілі назви в нижньому регістрі.
- **6 взаємопов'язаних сторінок** із повною перехресною навігацією (див. таблицю вище).
- **Семантична розмітка HTML5** — на кожній сторінці єдиний стандарт: `<header>` з логотипом, `<nav>` зі списком посилань, `<main>` із `<section>` та `<article>`, `<footer>` з 4-колонковою сіткою.
- **Ієрархія заголовків** — один `<h1>` на сторінку, логічні `<h2>`–`<h4>`; марковані `<ul>` та нумеровані `<ol>` списки; зовнішні посилання з `target="_blank"` і `rel="noopener noreferrer"`; усі `<img>` з інформативним `alt`.
- **Форма зворотного зв'язку** на `contacts.html` — поля імені, email, телефону, селекти спеціальності й формату сесії, textarea та чекбокс згоди з валідацією обов'язкових полів.
- **Валідність** — усі сторінки пройшли перевірку W3C Markup Validation Service без помилок; графіка у векторному форматі SVG.

## Лабораторна робота №3 — Використання CSS для оформлення та адаптації

Мета: освоїти базові прийоми використання CSS для створення сучасного, адаптивного та зручного інтерфейсу вебсайту.

Що зроблено:

- **Організація стилів** — стилі розбито на окремі зовнішні CSS-файли (`base.css`, `layout.css`, `components.css`, `forms.css`), об'єднані директивою `@import` у головному `style.css`.
- **Єдиний стиль за брендбуком** — усе оформлення через CSS-змінні; зі сторінок прибрано ~450 інлайн-стилів, замінених повторно використовуваними класами.
- **Адаптивний дизайн** — медіазапити `@media` з брейкпоінтами 1024px / 768px / 480px; бургер-меню для мобільної версії на чистому CSS (прихований чекбокс, `:checked ~ nav`).
- **Стилізація форм і валідація** — стани фокуса, повідомлення про помилки через `:user-invalid`/`:user-valid`, HTML5-атрибути `required`, `minlength`, `pattern`.
- **Верстка** — CSS Grid для сіток карток і макетів, Flexbox для шапки, hero та компонентів.
- **Кросбраузерність** — перевірено в Chrome, Firefox, Edge; вендорні префікси для Safari.

### Структура стилів

Стилі організовано в кілька окремих CSS-файлів, об'єднаних у головному `style.css` директивою `@import`:

```
css/
├── style.css        ← головний файл (@import усіх модулів)
├── base.css         ← дизайн-токени (CSS custom properties), reset, типографіка, таблиці
├── layout.css       ← контейнер, шапка, адаптивне бургер-меню, сітки, підвал, медіазапити
├── components.css   ← кнопки, hero, картки, бейджі, теги, модальні вікна
└── forms.css        ← поля форм, стани фокуса, клієнтська валідація
```

## Лабораторна робота №4 — Основи JavaScript (DOM, події, динамічний контент)

Додано клієнтську логіку на чистому JavaScript у файлі `js/main.js`, підключеному до всіх сторінок через `<script src="./js/main.js"></script>`.

### Структура скриптів

```
js/
└── main.js          ← уся клієнтська логіка ЛР4 (DOM, Events, Validation, LocalStorage)
```

### Реалізована JS-функціональність

- **Маніпуляція DOM** — пошук усіх карток `.card` через `querySelectorAll` зі зміною їх стилю; створення нового елемента `<p>` через `createElement()` і додавання в кінець `<main>` через `append()`.
- **Динамічний контент** — автоматичне відображення поточної дати у футері (`toLocaleDateString('uk-UA')`); акордеон «Показати більше» на головній сторінці, що розкриває прихований блок тексту.
- **Події кліків** — кнопка «Змінити тему» 🌙/☀️ у шапці (створюється динамічно), яка перемикає клас `dark-theme` на `<body>` і повністю змінює кольорову схему сайту через CSS-змінні.
- **Події миші** — підсвітка пунктів меню навігації при наведенні, реалізована JS-класами (`mouseover`/`mouseout` + `classList`), а не CSS `:hover`.
- **Події клавіатури** — клавіші `ArrowUp`/`ArrowDown` збільшують/зменшують розмір шрифту сторінки (у межах 12–22 px).
- **Обробка форми (`submit`)** — скасування стандартної відправки через `event.preventDefault()`, зчитування даних з усіх полів, вивід у консоль та у блок повідомлень під формою.
- **Клієнтська JS-валідація** — ім'я ≥ 3 символів, email з `@` і доменом (регулярний вираз), повідомлення ≥ 10 символів, перевірка телефону, вибору спеціальності та згоди. При помилці поле підсвічується червоним і під ним з'являється текст помилки; при успіху форма очищається та показується «Форма успішно надіслана!».
- **LocalStorage (бонус)** — збереження обраної теми (dark/light) та імені користувача з форми; при наступному відвідуванні тема відновлюється, а ім'я підставляється у форму.

## Використані технології

- **HTML5** — семантична розмітка (`header`, `nav`, `main`, `section`, `article`, `footer`), валідна за W3C.
- **CSS3 Custom Properties** — єдиний брендбук (кольори, шрифти, тіні, радіуси) у змінних `:root`.
- **CSS Flexbox** — шапка, навігація, hero-дії, картки, контактні списки, підвал.
- **CSS Grid** — сітки карток (`grid-3`, `grid-4` з `auto-fill`/`minmax`), двоколонкові макети, 4-колонковий підвал.
- **Медіазапити (`@media`)** — три брейкпоінти: 1024px (планшет), 768px (мобільний), 480px (малий екран).
- **Адаптивне бургер-меню** — реалізоване без JavaScript на прихованому чекбоксі (`:checked ~ nav`) з анімацією іконки у хрестик.
- **Клієнтська валідація форм** — HTML5-атрибути (`required`, `minlength`, `pattern`, `type="email"`) + CSS-псевдокласи `:user-invalid` / `:user-valid` з повідомленнями про помилки.
- **Модальні вікна без JS** — псевдоклас `:target`.
- **Кросбраузерність** — перевірено в Chrome, Firefox, Edge; додано вендорні префікси (`-webkit-backdrop-filter`, `-webkit-appearance`) для Safari.
- **Google Fonts** — Plus Jakarta Sans (заголовки), Inter (текст), JetBrains Mono (код/теги).
- **JavaScript (ES6+)** — робота з DOM (`querySelectorAll`, `createElement`, `append`), обробники подій (`click`, `mouseover`, `keydown`, `submit`), власна клієнтська валідація форми, перемикання теми та LocalStorage.

python -m http.server 8000
