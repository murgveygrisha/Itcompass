# Backend на Python (FastAPI + SQLite) для платформи ITCompass

Сучасний, швидкий та повністю документований бекенд для веб-порталу ITCompass.

---

## 🏗 Архітектура бекенду

* **Фреймворк:** [FastAPI](https://fastapi.tiangolo.com/) (сучасний стандарт асинхронних REST API в екосистемі Python).
* **База даних:** **SQLite 3** (`itcompass.db`) — автоматично ініціалізується та наповнюється 16 спеціальностями та профілями менторів.
* **Валідація даних:** [Pydantic v2](https://docs.pydantic.dev/) (строга типізація запитів та відповідей, перевірка коректності email та номерів телефонів).
* **Сервер застосунків:** [Uvicorn](https://www.uvicorn.org/) (високопродуктивний ASGI сервер).
* **Автоматична документація:**
  * **Swagger UI:** `http://127.0.0.1:8000/docs` (інтерактивне тестування всіх API прямо в браузері).
  * **ReDoc:** `http://127.0.0.1:8000/redoc`.

## 📂 Структура файлів бекенду

```text
D:\Web/
│
├── backend/
│   ├── app.py              # Головна точка входу: налаштування FastAPI, CORS, роути та роздача статики
│   ├── database.py         # Підключення до SQLite, створення таблиць та автонаповнення (seed)
│   ├── models.py           # Pydantic моделі валідації запитів (BookingCreate, ProfessionItem тощо)
│   └── requirements.txt    # Залежності проєкту (fastapi, uvicorn, pydantic, email-validator)
│
├── start_backend.bat       # Скрипт запуску в один клік для Windows
└── itcompass.db            # Файл реляційної бази даних SQLite (генерується автоматично)
```

## 🚀 Як запустити сервер

### Варіант 1. Запуск в один клік (Рекомендовано для Windows):
Двічі клікніть на файл **`start_backend.bat`** у папці `D:\Web`.  
Він автоматично:
1. Перевірить встановлення Python.
2. Встановить необхідні пакети через `pip install -r requirements.txt`.
3. Запустить веб-сервер на порту 8000.
4. Відкриє у браузері інтерактивну документацію Swagger.

### Варіант 2. Запуск через термінал / PowerShell:
```bash
# Перейдіть у папку бекенду:
cd D:\Web\backend

# Встановіть бібліотеки:
pip install -r requirements.txt

# Запустіть сервер:
python app.py
```
*Сервер запуститься за адресою: `http://127.0.0.1:8000`*

## 📡 Перелік API Ендпоінтів

| Метод | URL | Опис |
| :--- | :--- | :--- |
| `GET` | `/` | Головна сторінка сайту (роздача `index.html`) |
| `GET` | `/api/professions` | Отримати список усіх 16 спеціальностей (підтримує фільтри `?category=...` та `?search=...`) |
| `GET` | `/api/professions/{slug}` | Отримати повні дані окремої спеціальності (обов'язки, Hard/Soft навички, документація) |
| `GET` | `/api/mentors` | Отримати каталог наставників (підтримує фільтр `?tag=React`) |
| `GET` | `/api/mentors/{id}` | Отримати дані ментора за ID |
| `POST` | `/api/bookings` | **Створити нову заявку на консультацію** (зберігає дані форми у БД) |
| `GET` | `/api/bookings` | Список усіх заброньованих сесій (для адмін-панелі, фільтр `?status_filter=pending`) |
| `PATCH`| `/api/bookings/{id}/status` | Змінити статус заявки (`confirmed`, `completed`, `cancelled`) |
| `POST` | `/api/reviews` | Додати відгук про ментора |
| `GET` | `/api/reviews/{mentor_id}` | Отримати всі відгуки для конкретного ментора |
| `GET` | `/api/health` | Перевірка працездатності сервера та статистика кількості записів у базі даних |
