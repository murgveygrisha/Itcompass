# Backend на Python (Flask + SQLite) для платформи ITCompass

Повноцінний, автономний та надійний серверний бекенд для веб-порталу ITCompass.

---

## 🏗 Архітектура бекенду

* **Мова:** Python 3.9+
* **Фреймворк:** [Flask](https://flask.palletsprojects.com/)
* **База даних:** **SQLite 3** (`itcompass.db`) — автоматично ініціалізується та наповнюється 16 спеціальностями та профілями менторів.
* **CORS:** `Flask-Cors` (дозволяє безпечні крос-доменні AJAX-запити з будь-якого клієнта).
* **Панель адміністратора:** Вбудована інтерактивна веб-панель за адресою: `http://127.0.0.1:5000/admin`.

---


## 🚀 Як запустити сервер

### Варіант 1. Запуск у 1 клік (Рекомендовано для Windows):
Просто двічі клацніть файл **`start_backend.bat`** у папці `D:\Web`.  
Скрипт автоматично:
1. Перевірить наявність Python.
2. Встановить пакети через `pip install -r requirements.txt`.
3. Запустить Flask на порту 5000.
4. Автоматично відкриє у браузері головний сайт та адмін-панель.

### Варіант 2. Запуск через термінал:
```bash
cd D:\Web\backend
pip install -r requirements.txt
python app.py
```
*Сервер запуститься за адресою: `http://127.0.0.1:5000`*

## 📡 Перелік REST API Ендпоінтів

| Метод | URL | Опис |
| :--- | :--- | :--- |
| `GET` | `/` | Головна сторінка веб-сайту (`index.html`) |
| `GET` | `/admin` | **Інтерактивна веб-панель адміністратора** (керування заявками) |
| `GET` | `/api/professions` | Отримати список усіх 16 спеціальностей (підтримує фільтри `?category=...` та `?search=...`) |
| `GET` | `/api/professions/<slug>` | Детальна інформація про спеціальність (обов'язки, Hard/Soft навички, документація) |
| `GET` | `/api/mentors` | Отримати каталог наставників (підтримує фільтр `?tag=...`) |
| `GET` | `/api/mentors/<id>` | Отримати профіль ментора за ID |
| `POST` | `/api/bookings` | **Створити нову заявку на консультацію** (зберігає дані у SQLite та генерує Google Meet) |
| `GET` | `/api/bookings` | Список усіх заброньованих консультацій (підтримує фільтр `?status=...`) |
| `POST` / `PATCH` | `/api/bookings/<id>/status` | Оновити статус заявки (`pending`, `confirmed`, `completed`, `cancelled`) |
| `GET` | `/api/health` | Перевірка працездатності сервера та стан БД |
